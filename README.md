# 🛍️ RetailPulse AI: Customer Intelligence Platform

An end-to-end e-commerce customer analytics and machine learning dashboard designed to optimize customer segmentation, cross-selling strategies, and model transparency.

## 📊 Core Features & Architecture

1. **RFM Customer Segmentation:** Analyzes customer behavior using Recency, Frequency, and Monetary (RFM) metrics, grouping buyers into distinct behavioral clusters using K-Means clustering.
2. **Interactive Visualizations:** Features real-time cluster scatter plots, revenue metrics, and proportion breakdowns to visualize high-value customer segments.
3. **Market Basket Analysis (Association Rules):** Implements association rule mining (Apriori framework) to discover frequent product combinations, support metrics, and cross-selling insights (e.g., product bundling strategies).
4. **Explainable AI (XAI) / SHAP-style Feature Importance:** Visualizes global and local feature impact to explain *why* models categorize specific users into high-risk or high-value tiers, ensuring model interpretability for business stakeholders.
5. **Interactive Segment Predictor:** Allows business teams to input custom behavioral metrics for real-time customer tier classification and marketing recommendation triggers.
